# Sales Data Visualization

A Python project that generates charts showing revenue by store and payment method using data from an Excel spreadsheet.

## Features
- Read sales data from an Excel spreadsheet
- Analyze revenue by store
- Analyze revenue by payment method
- Generate data visualizations

## Technologies
- Python
- Pandas
- Plotly
- Excel

## How to Run
1. Install the required dependencies.
2. Place the input spreadsheet in the location expected by the script.
3. Run the main Python script.

## Notes
Do not upload spreadsheets containing private or confidential information.

## Project Context
Developed as part of a Python programming course.
